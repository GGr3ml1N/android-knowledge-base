`psql` — терминальный клиент PostgreSQL

## СИНОПСИС

psql [ОПЦИИ]... [имя_базы]

## ОПИСАНИЕ

psql — интерактивный терминальный клиент PostgreSQL: выполняет SQL, показывает схему БД, даёт доступ к метаинформации. Стандартный инструмент для проверки данных, когда API и БД расходятся.

## ПОДКЛЮЧЕНИЕ

Параметры задаются опциями или переменными окружения:

| Способ | Опция | Переменная окружения |
|---|---|---|
| Хост | `-h <хост>` | `PGHOST` |
| Порт | `-p <порт>` | `PGPORT` |
| Пользователь | `-U <имя>` | `PGUSER` |
| База | `-d <имя>` | `PGDATABASE` |
| Пароль | запрос интерактивно, `-W` принудительно | `PGPASSWORD` |

Для локального PostgreSQL в Docker хост и порт обычно не нужны — psql запускается внутри контейнера (см. ПРИМЕРЫ).

## ОПЦИИ

| Опция | Действие |
|---|---|
| `-c <команда>` | Выполнить одну команду/SQL и завершиться. Можно метакоманду: `-c '\dt'` |
| `-f <файл>` | Выполнить SQL из файла |
| `-l` | Список баз данных и завершиться |
| `-t, --tuples-only` | Только строки данных, без заголовков (для скриптов) |
| `-A, --no-align` | Не выравнивать колонки (вывод через разделитель) |
| `-o <файл>` | Записать вывод в файл |
| `-v <имя>=<значение>` | Переменная psql для SQL/скриптов |
| `--csv` | Вывод результата в CSV (psql ≥ 12) |

## МЕТАКОМАНДЫ (backslash)

Вводятся внутри интерактивной сессии, начинаются с `\`:

| Команда | Действие |
|---|---|
| `\dt` | Список таблиц (`\dt+` — с размерами) |
| `\d <таблица>` | Структура таблицы: колонки, типы, ключи, индексы |
| `\di` | Список индексов |
| `\l` | Список баз данных |
| `\du` | Список ролей/пользователей |
| `\conninfo` | Текущее подключение |
| `\x` | Переключить расширенный вывод (одна колонка на строку, удобно для широких строк) |
| `\timing` | Показывать время выполнения каждого запроса |
| `\i <файл>` | Выполнить SQL из файла |
| `\copy <таблица> FROM/TO '<файл>' CSV` | Импорт/экспорт CSV (клиентская сторона) |
| `\?` | Справка по метакомандам |
| `\q` | Выйти |

## ПРИМЕРЫ

```bash
# Одна команда против локального PostgreSQL в Docker
docker exec -it fitness-postgres psql -U postgres -d fitness -c '\dt'

# Список таблиц с выводом только строк (для скриптов)
docker exec -it fitness-postgres psql -U postgres -d fitness -t -c '\dt'

# Интерактивная сессия
docker exec -it fitness-postgres psql -U postgres -d fitness

# Подключение из хоста (порт проброшен -p 5432:5432)
PGPASSWORD=postgres psql -h localhost -p 5432 -U postgres -d fitness -c '\dt'

# Дамп таблицы в CSV
docker exec -it fitness-postgres psql -U postgres -d fitness \
  -c "\copy workout TO '/tmp/workout.csv' CSV HEADER"
```

Интерактивно, внутри сессии:

```sql
SELECT * FROM workout;          -- все тренировки
\d workout                      -- структура таблицы
\x                              -- расширенный вывод вкл/выкл
UPDATE workout SET name = 'Жим' WHERE id = 1;
\dt                             -- список таблиц
\q                              -- выйти
```

## ЗАМЕЧАНИЯ

- Без `-d` psql подключается к базе, совпадающей с именем пользователя.
- Пароль при интерактивном входе не отображается; в скриптах используют `PGPASSWORD`.
- Все, что начинается с `\` — обрабатывает сам psql, а не сервер; всё остальное отправляется в PostgreSQL как SQL.
- Внутри `docker exec` флаг `-it` обязателен для интерактивной сессии.
