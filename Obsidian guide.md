# 📖 Гайд по работе с базой знаний в Obsidian (Windows)

Этот гайд поможет вам получить доступ к нашей общей базе знаний, всегда иметь под рукой актуальные данные и случайно ничего не сломать. 

База знаний хранится в системе Git (это как облако, но для текстовых файлов). Мы будем использовать **Obsidian** — удобную программу для чтения и работы с заметками.

---

## 🛠 ЭТАП 1. Первичная настройка (делается один раз)

### Шаг 1. Установка программ
1. Скачайте и установите **Obsidian**: [официальный сайт](https://obsidian.md/) (нажмите большую кнопку Download для Windows).
2. Скачайте и установите **Git**: [официальный сайт](https://git-scm.com/downloads/win). 
   * *Лайфхак:* В установщике Git просто постоянно нажимайте «Далее» (Next), оставляя все настройки по умолчанию.

### Шаг 2. Скачивание библиотеки (git clone)
Нам нужно один раз «стянуть» файлы из общего облака на ваш компьютер.

1. Создайте на компьютере папку, где будет жить библиотека (например, в `Документы` создайте папку `Obsidian`).
2. Откройте эту папку.
3. Кликните **правой кнопкой мыши** по пустому месту внутри папки и выберите **«Открыть в Терминале»** (в Windows 11) или **«Git Bash Here»** (если у вас Windows 10).
4. В появившемся окне (оно может быть черным или синим) вставьте следующую команду, заменив ссылку на нашу актуальную:
   ```bash
   git clone https://github.com/ваш-репозиторий.git
   ```
   *(Чтобы вставить текст в терминал, иногда нужно просто кликнуть правой кнопкой мыши внутри окна).*
5. Нажмите **Enter**. Побегут строчки — это нормально. Когда процесс завершится и курсор снова замигает, внутри вашей папки появится новая папка с названием репозитория.

### Шаг 3. Открытие библиотеки в Obsidian
1. Запустите **Obsidian**.
2. В меню слева (или в окне приветствия) нажмите **«Open folder as vault»** (Открыть папку как хранилище).
3. Выберите ту самую папку, которая только что скачалась через Git (она будет внутри вашей папки `Obsidian`).
4. Готово! Вы внутри базы знаний.

---

## 🔄 ЭТАП 2. Ежедневная работа (получение обновлений)

Чтобы видеть новые заметки и изменения, которые добавили коллеги, библиотеку нужно «обновлять». Делайте это в начале рабочего дня.

### Как обновить данные (git pull)
1. Откройте папку с библиотекой на компьютере (ту, что вы скачали).
2. Снова кликните **правой кнопкой мыши** по пустому месту внутри папки → **«Открыть в Терминале»** (или Git Bash Here).
3. Введите команду:
   ```bash
   git pull
   ```
4. Нажмите **Enter**. Программа скачает новые файлы. Если всё уже актуально, она напишет `Already up to date` (Уже актуально).

---

## 🔒 ЭТАП 3. Режим «Только для чтения» (Защита от случайных изменений)

Поскольку вы используете библиотеку для ознакомления, нам нужно избежать случайного редактирования или удаления чужих заметок. Мы используем два уровня защиты.

### Уровень 1. Повседневный (Режим чтения в Obsidian)
Когда вы открываете заметку, она может открыться в режиме редактирования. 
* **Правило:** Всегда переключайте заметку в режим чтения. 
* **Как:** Нажмите комбинацию клавиш **`Ctrl + E`** (или нажмите на иконку книги/карандаша в правом верхнем углу). 
* *В этом режиме текст выглядит красиво, как в статье, и вы физически не сможете случайно стереть абзац, нажимая клавиши.*

### Уровень 2. Технический (Блокировка файлов в Windows)
Чтобы полностью заблокировать возможность редактирования на уровне системы:

1. Нажмите **правой кнопкой мыши** на **корневую папку** библиотеки (на ту, что скачалась через Git) и выберите **«Свойства»**.
2. В самом низу окна поставьте галочку **«Только для чтения»**.
3. Нажмите **«Применить»**.
4. Появится окошко. Выберите **«Применить ко всем вложенным элементам»** и нажмите ОК.

> ⚠️ **Важный нюанс:** После этой блокировки Obsidian может выдавать небольшую ошибку при закрытии программы, говоря, что не может сохранить «состояние интерфейса» (какие вкладки были открыты). **Это нормально и безопасно!** Просто нажимайте «Отмена» или «Не сохранять» при закрытии. Сами тексты заметок при этом остаются в полной безопасности и не меняются.

## 🛡️ Ваша безопасность (Почему вы ничего не сломаете)

**Главное правило:** Если вы всё же случайно что-то отредактировали и сохранили — **не паникуйте**. 
Поскольку у вас нет прав на отправку изменений (команда `git push`), ваши правки останутся **только на вашем компьютере** и никогда не попадут в общую базу. При следующем `git pull` система сама перезапишет ваши случайные изменения актуальными данными из облака. Общая база под надежной защитой!
